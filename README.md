# 🍽️ Menú Digital de Restó

Aplicación web de un restaurante desarrollada con React y Vite como parte de un trabajo práctico de Desarrollo Web.

## ✨ Funcionalidades

- Encabezado con nombre, eslogan y estado del restaurante.
- Tarjetas con nombre, descripción y precio de cada plato.
- Indicador visual para los platos agotados.
- Etiquetas para identificar características de los platos.
- Resumen del menú con la cantidad total de platos, los disponibles y el precio promedio.

## 🛠️ Tecnologías utilizadas

- React
- JavaScript
- CSS
- Vite
